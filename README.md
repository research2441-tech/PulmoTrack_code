# PulmoTrack

Code for the manuscript *PulmoTrack: Patient-Level Conformal Risk Control of Lesion Change Calls and Calibrated Burden Trajectories in Longitudinal Multicentre Chest CT*.

PulmoTrack segments every chest CT examination independently and moves all use of the prior examination into a longitudinal reliability layer:

1. birth-death lesion association between registered examinations;
2. cross-examination evidence scoring of every unmatched lesion (candidate new or resolved lesion);
3. patient-level conformal risk control (CRC) of the expected number of false change calls per patient;
4. normalised conformal intervals for the lung-normalised burden ratio, with a refer-to-reader rule for response categories.

All experiments run on **PulmoTrack-Sim**, an in-silico longitudinal multicentre chest CT cohort generated by `sim.py`. No patient data are used or distributed. Absolute numbers are therefore not comparable with clinical systems; see Section VII of the paper.

## Requirements

Python 3.10 or later, CPU only. Install the packages with `pip install -r requirements.txt`. The reported runs used two CPU cores.

## Reproducing the paper

```bash
bash run_all.sh
```

The script regenerates the cohort, registrations, pretraining, all backbone configurations, inference, association fitting, evaluation, statistics (`res/summary.json`) and every figure. On two cores a full run takes roughly a day. `queue.sh` skips any job whose output already exists, so an interrupted run resumes where it stopped.

The `result_*.json` files are the outputs of the reported run. Every number in the manuscript is read from `result_summary.json` (written by `results.py`) and `result_extra.json` (backbone selection and costs); `run_all.sh` writes fresh copies to `res/`. The folder is flat: generated data, checkpoints, predictions and figures go to `data/`, `ckpt/`, `res/` and `figs/`, which the script creates.

## Files

| File | Role |
|---|---|
| `sim.py` | Simulator: anatomy (five lobes, incomplete fissures, vessels), lesion processes (solid, ground-glass, part-solid; growth, regression, resolution, new lesions; crowded "dense" process), breathing deformation, five acquisition sites A to E |
| `gen.py` | Patient-level splits: train, val, val2, cal, cal2, test (sites A to C), extD, extE (held-out sites), dense (crowded stress cohort), ssl (unlabelled single scans) |
| `cohort_stats.py` | Cohort characteristics table (`res/cohort.json`) |
| `demons.py`, `grids.py`, `warp.py` | Symmetric demons registration of consecutive examinations and warping |
| `common.py` | Data loading and intensity normalisation |
| `model.py` | Residual 3D U-Net with optional lobe head, lung gate and interval-gated prior-map memory; UNETR-lite; masked-volume modelling head |
| `pretrain.py` | Masked-volume pretraining of the encoder on the unlabelled split |
| `train.py` | Training of every configuration (`unet`, `unetssl`, `gate`, `nomem`, `full`, `paired`, `unetr`; suffix `25` trains on 25% of patients) |
| `sliding.py`, `infer.py` | Gaussian-weighted sliding-window inference and test-time adaptation (`tent`, `anat`) |
| `track.py` | Instances, birth-death association, event features, response categories |
| `fit_assoc.py` | Fits association parameters and selects the event matcher on validation predictions |
| `evaluate.py` | Per-scan and per-interval evaluation records |
| `analysis.py` | Evidence scorer, conformal risk control, conformal selection with Benjamini-Hochberg, burden intervals, statistics |
| `select_backbone.py` | Validation-based backbone selection |
| `tta_sweep.py` | Adaptation strength sweep at site D |
| `results.py` | Builds `res/summary.json` |
| `cost.py` | Parameter counts and wall-clock costs |
| `diag.py`, `fig_arch.py`, `fig_cohort.py`, `plots.py` | Figures |
| `queue.sh`, `run_all.sh` | Job runner and full reproduction script |

## Key settings

Grid 48 x 64 x 64 voxels at 6 x 5 x 5 mm; channels 8/16/32/64; 12 training epochs; sliding windows 32 x 48 x 48 (eight per volume). Seeds are fixed (`1000 + patient id` for the simulator, the configuration seed for training).
